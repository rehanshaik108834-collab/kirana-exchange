Transforming how India's 12 million+ neighbourhood grocery shops manage inventory, reduce dead stock, and unlock volume pricing through an event-driven peer-to-peer network.

## 🚀 Engineering Highlights

- Strict Database-per-Service
- Transactional Outbox Pattern
- Optimistic Concurrency Stock Guards
- Distributed Saga Orchestrator
- Atomic Redis Lua Rate Limiting

## 🛠 Tech Stack

- **Frontend:** React 18, Vite, TS, Tailwind v4
- **Backend:** Node.js, NestJS, Python, FastAPI
- **Infra:** Postgres 16, Redis 7, RabbitMQ 3

## ⚙️ Quickstart

```bash
docker compose -f infra/docker-compose.yml up -d
pnpm install
pnpm build
```
