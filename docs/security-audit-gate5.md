# Phase 11 Security Audit & Go/No-Go Gate #5 Sign-Off

This document records the OWASP Top 10 / OWASP API Security audit, resilience hardening, and Go/No-Go Gate #5 verification for Kirana Exchange.

## 1. OWASP Top 10 & API Security Verification Matrix

| OWASP Category                                   | Control Implemented in Kirana Exchange                                                                                                                                                                                                                                                     | Automated Proof / Location                                                                                                                                      |
| :----------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A01 Broken Access Control / API1 BOLA (IDOR)** | Every shop-owned endpoint denies by default unless `x-user-role === 'admin'` or verified `x-shop-id === targetShopId`. Gateway overwrites client-supplied identity headers from verified JWTs and blocks `/internal/` (including URL-encoded, uppercase, and `..` traversal variants).     | `apps/api-gateway/test/owasp-authorization.test.ts`, `apps/inventory-service/test/idor-authz.test.ts`, `apps/shop-service/test/reputation-and-disputes.test.ts` |
| **A02 Cryptographic Failures**                   | Passwords hashed with Argon2id; refresh tokens and 6-digit swap handover PINs stored only as salted SHA-256 hashes verified with `crypto.timingSafeEqual`. Inter-service identity signed with HMAC-SHA256 (`X-Internal-Signature`) + 60s skew window.                                      | `libs/common/src/security/internal-auth.ts`, `libs/common/test/internal-auth.unit.test.ts`, `apps/saga-orchestrator/src/saga.service.ts`                        |
| **A03 Injection**                                | Strict parameterized SQL (`$1, $2` in PostgreSQL/TypeORM and named binds in SQLAlchemy) across all 10 isolated databases. `ValidationPipe({ whitelist: true, forbidNonWhitelisted: true })` enforced globally on all NestJS services; Pydantic v2 models validate all FastAPI inputs.      | All `apps/*/src/main.ts`, `services-py/*/src/*/api.py`                                                                                                          |
| **A04 Insecure Design / Concurrency**            | Two-tier idempotency (Redis + PostgreSQL unique constraints), atomic conditional stock `UPDATE ... WHERE (qty - reserved_qty) >= $1`, and `pg_try_advisory_xact_lock` for group-buy window closures.                                                                                       | `apps/inventory-service/test/saga-inventory.service.test.ts`, `apps/groupbuy-service/test/groupbuy.service.test.ts`                                             |
| **A05 Security Misconfiguration**                | `X-Powered-By` disabled; `SecurityHeadersMiddleware` sets `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, `Permissions-Policy`, `Content-Security-Policy`, and conditional HSTS. RFC 9457 `ProblemDetailsFilter` strips internal stack traces. | `apps/api-gateway/src/middleware/security-headers.middleware.ts`, `apps/api-gateway/test/resilience.test.ts`                                                    |
| **A06 Vulnerable & Outdated Components**         | Automated `Trivy` filesystem scan (`CRITICAL,HIGH`) in GitHub Actions plus `pnpm audit` and Python dependency checks.                                                                                                                                                                      | `.github/workflows/ci.yml` (`security-audit` job)                                                                                                               |
| **A07 Identification & Authentication Failures** | Short-lived JWT access tokens (`15m`) + rotating refresh tokens + Redis `auth:denylist:{jti}` checked on every request (`503` fail-closed if Redis is down unless `DENYLIST_FAIL_OPEN=true`). Account lockout & token-bucket rate limiting (`100 req/min`, burst `30`).                    | `apps/api-gateway/test/guards.test.ts`, `apps/api-gateway/test/chaos-drills.test.ts`                                                                            |
| **A08 Software & Data Integrity Failures**       | Transactional Outbox (`ADR-003`) + `processed_messages` consumer deduplication + SHA-256 verified simulator manifests + non-destructive DLQ inspection & audited replay CLI.                                                                                                               | `libs/common/test/chaos-drills.unit.test.ts`, `libs/common/test/dlq-replay.unit.test.ts`                                                                        |
| **A09 Security Logging & Monitoring**            | Structured `pino` / `structlog` JSON logs carrying `X-Correlation-Id` across HTTP and RabbitMQ boundaries; immutable `audit_logs` on dispute resolutions.                                                                                                                                  | `apps/api-gateway/src/middleware/correlation-id.middleware.ts`, `apps/shop-service/src/dispute.service.ts`                                                      |
| **A10 Server-Side Request Forgery (SSRF)**       | `GatewayProxyController` routes exclusively to fixed, environment-configured internal base URLs per service; client-supplied hosts/URLs are never fetched.                                                                                                                                 | `apps/api-gateway/src/proxy.controller.ts`                                                                                                                      |
